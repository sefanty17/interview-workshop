## 1. 接口

| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/api/interviewers` | `List<InterviewerSummary>` |
| GET | `/api/interviewers/{code}` | `InterviewerDetail`（含完整 `personaPrompt`） |
| GET | `/api/scripts` | `List<ScriptSummary>`，`?job=` 可选过滤 |
| GET | `/api/scripts/{code}` | `ScriptDetail`（含 `chapters: List<ChapterView>`，`events` 原样返回 JSON 字符串） |
| GET | `/api/profile` | `ProfileView` |
| PUT | `/api/profile` | `ProfileView`（按 `ProfileUpdateRequest` 更新后返回） |

`code` 找不到一律 `404`，返回体 `{"error":"not_found","code":"..."}`。

### 1.1 DTO 字段

- `InterviewerSummary`：`code / name / subtitle / cardTitle / avatarMode / scale / offsetX / offsetY / bubbleTop / bubbleLeft / displayRole / opening / sortOrder`
  —— **不含** `personaPrompt`（列表不吐长文本，对齐 LingChat 列表页只取卡面字段）。
- `InterviewerDetail`：`InterviewerSummary` 的全部 + `cardInfo / personaPrompt / exampleDialogue / thinkingMessage / userAlias / userAliasSubtitle / followUp / speed`
- `ScriptSummary`：`code / scriptName / introChapter / description / recommandStart / orderNum / triggerMode / jobCode / level / companyStyle / scriptSettings / interviewerCode`
  （`interviewerCode` 由 `interviewerId` 查 `InterviewerRepository` 得到）
- `ScriptDetail`：`ScriptSummary` 全部 + `List<ChapterView> chapters`
- `ChapterView`：`code / name / orderNum / events`（`events` 是 String，原样给前端）
- `ProfileView` / `ProfileUpdateRequest`：照 `UserProfile` 实体字段，去掉 `id / createdAt` 之类由服务端生成的字段。

`interviewer` 列表按 `sort_order` 升序；`script` 列表按 `order_num` 升序。
`chapters` 按 `order_num` 升序。

### 1.2 Repository 需要的新方法（只增）

```java
// InterviewerRepository
Optional<Interviewer> findByCode(String code);
List<Interviewer> findAllByOrderBySortOrderAsc();

// InterviewScriptRepository
Optional<InterviewScript> findByCode(String code);
List<InterviewScript> findAllByOrderByOrderNumAsc();
List<InterviewScript> findAllByJobCodeOrderByOrderNumAsc(String jobCode);

// InterviewChapterRepository
List<InterviewChapter> findByScriptIdOrderByOrderNumAsc(Long scriptId);

// UserProfileRepository
Optional<UserProfile> findTopByOrderByIdAsc();     // 单用户，取第一条
```

Spring Data JPA 派生查询；若方法已存在就别重复加。

### 1.3 Profile

`GET /api/profile`：库里没有记录就返回一条**兜底默认身份**（对齐 LingChat 默认玩家身份）：
昵称 `候选人`，其余字段留空/`0`，**不要写库**。
`PUT /api/profile`：有则更新，无则新建；`id` 忽略。

## 2. 单测（`src/test/java/cn/edu/zjut/interview/api/`）

用 H2 mem（`application-test.yml` 已存在）、`@SpringBootTest` + `MockMvc` 或 `TestRestTemplate`：

1. `InterviewerControllerTest`：`GET /api/interviewers` 返回 4 条且 code 为 `strict/friendly/pressure/expert`；`GET /api/interviewers/strict` 的 `personaPrompt` 非空；`GET /api/interviewers/nope` → 404。
2. `ScriptControllerTest`：`GET /api/scripts` 返回 4 条；`?job=java` 返回 2 条；`GET /api/scripts/java-strict` 的 `chapters` 长度为 6 且第一个 chapter 的 `code == "intro"`；chapters 的 `events` 能被 Jackson 解析成数组。
3. `ProfileControllerTest`：`GET` 返回兜底身份；`PUT` 后 `GET` 能读到新值。

种子数据来自 `backend/src/main/resources/data-h2.sql` 与 `scripts-h2.sql`；
若测试库没加载，用 `spring.sql.init.mode=always` + 指向 classpath 的 schema/data 脚本（看 `application-test.yml` 现况决定，**改动 `application-test.yml` 只允许追加属性，不许删**）。

**不许删改现有 26 个测试**，全部必须通过。
