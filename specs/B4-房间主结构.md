# 规格 B4：自由对话房间（1:1 重写）

## 背景

当前 `frontend/src/views/InterviewRoomView.vue`（391 行）是一个**消息列表**式界面：
多轮对话往下堆、整体滚动。这与 LingChat 的自由对话**范式不同**。

LingChat 的房间是**单句推进**：
- 标题栏常驻（角色名 + 副标题 + 情绪 + 操作按钮组）
- 正文区只显示**当前这一句**，逐字打出
- 点 ▼ 或回车：正在打字则立即打完；已打完则推进到下一句
- 历史对话通过「历史」按钮打开面板查看，不堆在正文里
- 立绘在对话框上方，随情绪切换图片

本批要把这个范式完整搬过来。

## 三、`store/roomStore.ts`（新增，替代原版 uiStore 里的房间字段）

原版 `GameDialog` 直接读 `uiStore.showCharacterTitle` / `showCharacterSubtitle` /
`showCharacterEmotion` / `isNarrowScreen` / `containerWidth`。我们建一个对应的 store：

```ts
export const roomStore = reactive({
  showCharacterTitle: "",      // 角色名
  showCharacterSubtitle: "",   // 副标题（职位）
  showCharacterEmotion: "正常", // 情绪标签文案
  isNarrowScreen: false,       // 由 window.innerWidth < 768 决定
  containerWidth: 70,          // 对话框宽度百分比
  lines: [] as RoomLine[],     // 已产出的句子队列
  cursor: 0,                   // 当前显示到第几句
});
export interface RoomLine {
  role: "ai" | "user";
  text: string;                // 已剥离符号的台词
  motion?: string;             // （动作）文本
  emotion?: string;            // 【情绪】
  final: boolean;
}
```

同时提供 `advance()` / `pushLine()` / `resetRoom()` 三个方法。

`isNarrowScreen` 用 `matchMedia("(max-width: 768px)")` 监听，与 Tailwind 的 `md` 断点一致。

## 四、`GameDialog.vue` 的照搬要点

### 4.1 外层容器
```html
<div class="game-dialog relative z-2 flex w-full scrollbar-thin
            [scrollbar-color:var(--accent-color)_transparent] justify-center p-3.75
            transition-all duration-200 ease-[cubic-bezier(0.25,0.46,0.45,0.94)]
            before:pointer-events-none before:absolute before:-top-10 before:right-0
            before:left-0 before:h-10 before:bg-linear-to-b before:from-transparent
            before:via-[rgba(0,14,39,0.3)] before:to-[rgba(0,14,39,0.6)] before:content-['']"
     :class="{ 'max-h-[40dvh]': !roomStore.isNarrowScreen }">
```
**这段 before: 压暗带不能省**，它覆盖 panel 上方的 40px 渐变遮罩，是原版视觉的关键。

### 4.2 内层宽度
`<div :style="{ width: containerWidth + '%' }" class="relative">`

### 4.3 标题栏（严格照抄）
- 整体 `mb-2 flex items-baseline`
- 角色名：`mr-3.75 text-2xl font-bold text-shadow-[inherit]`
- 副标题：`text-xl font-bold text-[#6eb4ff] text-shadow-[inherit]`，窄屏 `v-show="!isNarrowScreen"`
- 情绪：`relative mx-4 shrink-0 text-xl font-bold whitespace-nowrap text-[#ff77dd]`
  外层套 `<Transition name="emotion-slide">`，`:key` 绑情绪值
- 标题切换用 `<Transition name="title-slide">`，`:key="title + subtitle"`
- 右侧按钮组：`ml-auto flex min-w-0 items-baseline`，内部 8 个 `<Button type="nav" icon="..." />`
  原版图标顺序：`background` / `hand` / `history` / `mic` / 截图 / `upload` / `download` / `close`

我们的取舍（按钮保留，功能降级）：
| 按钮 | 我们的行为 |
|---|---|
| background（场景） | 打开场景面板（B5 才做，先 `alertDialog("场景面板待接入")`） |
| hand（触摸模式） | 原版是摸头互动，我们提示"待接入" |
| history（历史） | 打开历史面板，列出 `roomStore.lines` 全文（这个要真做） |
| mic | `disabled`，提示"语音输入待接入" |
| 截图 | 提示"待接入" |
| upload / download | 快捷存档/读档，写 localStorage（可以真做） |
| close | **结束本场面试**（我们改这里的语义）：弹 `confirmDialog("结束本场面试并生成报告？")`，确认后走现有 finish 逻辑 |

`title-slide` / `emotion-slide` 两个 Transition 的 CSS 从原版 `<style scoped>` 抄（约 930-968 行）。

### 4.4 正文区
两块互斥显示：

```html
<!-- AI 回应态：两个容器，台词白字 + 动作灰字，各自独立打字机 -->
<div v-show="state === 'responding'" ref="inlineDisplayRef"
     class="response-display my-1.25 max-h-[50dvh] min-h-30 flex-1 resize-none
            overflow-y-auto border-none bg-transparent font-[inherit] text-xl font-bold
            break-all whitespace-pre-line outline-none text-shadow-[inherit]"
     @keydown.enter.exact.prevent="sendOrContinue" @click="sendOrContinue">
  <div ref="dialogueLineRef" class="whitespace-pre-line text-white"></div>
  <div ref="motionLineRef" class="whitespace-pre-line text-[#9ca3af]"></div>
</div>

<!-- 输入态 -->
<textarea v-show="state !== 'responding'" id="inputMessage"
          class="my-1.25 max-h-[50dvh] min-h-30 flex-1 resize-none border-none
                 bg-transparent font-[inherit] text-[max(1.25rem,16px)] font-bold
                 transition-all duration-300 outline-none text-shadow-[inherit]
                 placeholder:text-white/50 placeholder:shadow-none"
          :placeholder="placeholderText" v-model="inputMessage"
          @keydown.enter.exact.prevent="sendOrContinue" :readonly="!isInputEnabled" />
```

**分两块的用意**：台词与动作各跑一个打字机，并行显示。不要合并成一个 div。

### 4.5 分割线与发送
```html
<div class="dialog-divider-glow my-1.5"></div>
<button id="sendButton"
        class="absolute right-0 bottom-0 translate-x-full cursor-pointer rounded-[5px]
               border-none bg-transparent px-2 py-2 font-[inherit] text-sm font-bold
               text-[#04bcff] transition-all duration-300 text-shadow-[inherit]
               hover:bg-transparent hover:text-[rgba(136,255,251,0.827)]
               disabled:cursor-not-allowed disabled:bg-[#333] disabled:opacity-70">▼</button>
```

### 4.6 打字机
原版逻辑在 script 里（读 `typeText` / `typeDialogue` 一类函数）。照搬实现：
- 每字符间隔从原版常量取（约 30~40ms，自行从代码确认）
- 新字符 `span` 淡入 + 上浮（原版有 `lc-char` 或类似 class，`lingchat.css` 里已有 `.lc-char` 可复用）
- 打字中点击 → 立即输出全文，`isTyping = false`

## 七、`InterviewRoomView.vue` 重写要求

### 必须保留的现有逻辑
- `appStore.session`（jobId / personaId / mode / messages / startedAt / elapsed）
- 计时器与 `timerText`
- `finish()` → 写报告 → 跳转 `/report`
- `confirmDialog` 结束确认
- 顶部进度：`mode === "script"` 时显示「第 N / M 题 + 进度条」，`mode === "free"` 时显示「自由面试 · 第 N 轮」，无进度条
- 假回复生成函数（`askQuestion` / 追问话术池），S3 换成真 LLM

### 新的页面结构
```
<div class="relative h-dvh w-full overflow-hidden">
  <GameBackground />                          ← 背景（最底层）
  <GameRolesStage>                            ← 立绘（居中，底部对齐）
    <GameRoleAvatar :code="personaId" :emotion="currentEmotion" />
  </GameRolesStage>

  <!-- 顶部状态（我们独有的进度指示，保持轻量，不抢标题栏位置） -->
  <div class="absolute inset-x-0 top-0 z-20 ..."> ... 结束面试 ... </div>

  <div class="absolute inset-x-0 bottom-0 z-10">
    <GameDialog ... />                        ← 对话框（底部）
  </div>
</div>
```

**注意层级**：原版对话框 `z-2`，立绘在它下面但在背景之上。
顶部状态条沿用现有样式（`nav-btn` + 白字阴影），不要做成一整条不透明 bar。

### 数据流
```
用户输入 → sendOrContinue()
  ├─ state === "responding" 且正在打字 → 立即输出全文
  ├─ state === "responding" 且已打完 → advance() 到下一句；队列空则回到输入态
  └─ state === "input" → pushLine(user) + 生成 AI 回复 pushLine(ai) → 开始播第一句
```

`currentEmotion` 取自当前行的 `emotion`，缺省「正常」；切换时 `GameRoleAvatar` 换图。
