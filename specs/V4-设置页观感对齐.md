# V4 · 设置页观感对齐原版（功能不动）

> 主线写规格，子 agent 执行。
> **只改观感**：布局、层级、间距、控件样式。
> **不许动功能**：不改数据读写、不改设置项键名、不新增/删除设置项、不改中文文案。

## 0. 背景

智豪反馈：「通用设置的前端太丑」「其实所有设置页面和剧本编辑器的前端和 lingchat 都很不一样」。
按已拍板的顺序，V1（主题地基）与本批之间是"地基 → 页面"关系：**V1 已把 `--color-brand`
补上，原版那批 `bg-brand/…` 类现在才真正生效**，所以本批的第一件事是"回退 V1 之前
手打的补丁"，把页面恢复到原版写法。

## 1. 蓝本（逐字对照，不要凭感觉改）

| 蓝本 | 用途 |
|---|---|
| `references/lingchat/src/components/settings/Settings.vue` | 设置外壳（Tab 列表、指示条、滑入过渡） |
| `references/lingchat/src/components/settings/pages/SettingsGeneral.vue` | 通用设置页 |
| `references/lingchat/src/components/settings/SettingItem.vue`（或等价） | 单项行布局 |

先 `ls` 确认文件存在；名字对不上就在报告里写你实际用的路径。

## 2. 改动 A · 补丁回退（先做，收益最大）

全项目搜索 `var(--accent-color)` 的**类名任意值**写法，回退成原生 brand 类：

| 现有 | 回退为 |
|---|---|
| `text-[var(--accent-color)]` | `text-brand` |
| `bg-[var(--accent-color)]` | `bg-brand` |
| `border-[var(--accent-color)]` | `border-brand` |
| 带透明度修饰符的变体 | 透明度跟着搬（如 `bg-[var(--accent-color)]/12` → `bg-brand/12`） |

**边界**：
- `<style>` 块里 CSS 属性用 `var(--accent-color)` 是**合法用法，不动**。
- `components/schedule/` 全目录不动（本项目自建，原版无对应物）。
- `styles/*.css` 里的定义不动。
- **本批只准改 `components/settings/` 与 `views/SettingsView.vue`**（其余目录归别的批次）。

## 3. 改动 B · 设置外壳观感

对照原版 `Settings.vue`：
1. Tab 列表（本项目 11 个 Tab：面试官 / 剧本冒险 / 通用 / 背景 / 声音 / 成就 /
   存档 / 高级设置 / 日志 / 插件 / 面试规则）——**顺序、图标、分组都不许改**。
2. 左侧指示条（原版选中态的指示条位置/尺寸/颜色/过渡曲线）——照搬。
3. 面板滑入过渡（原版推入推出曲线）——照搬。
4. 外壳内边距、圆角、背景层次（原版的层次感靠 `bg-brand/…` + 半透明）——补齐。
5. **只改样式与层级，不动 Tab 数据本身**。

## 4. 改动 C · 通用设置页控件观感

对照原版 `SettingsGeneral.vue`：
1. 分组标题（字号/字重/字距/间距）照搬。
2. 行布局（label 与控件的对齐、gap、最小高度）照搬。
3. 开关 / 滑块 / 下拉 / 文本框：换成原版同款样式与过渡曲线。
   - 本项目已有 `components/base/widget/Toggle.vue` 等组件，优先复用并补齐样式，
     **不要新造一套平行控件**。
4. **设置项的键名、默认值、读写逻辑一字不改**。

## 5. 约束

1. 不许跑任何 git 命令（含只读）。
2. **只准改** `frontend/src/components/settings/` 与 `frontend/src/views/SettingsView.vue`。
   其它目录（含 `script-editor/`、`game/`、`store/`、`styles/`）一律不许动。
3. 不许加 `any` / `@ts-ignore` / 删类型。
4. 不许改任何中文文案、不许增删设置项。
5. 不许引入新依赖。
6. 不许改 `styles/` 下的既有变量与选择器（那是 V1 的地基）。
