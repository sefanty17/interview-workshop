函数（全部 `fetch`，错误体是 `{error, message}`，沿用现有 `api/scripts.ts` 的 `readError` 写法，**抽成一个共用 `readError`**）：

```ts
getSchema(): Promise<ScriptSchema>                                  GET  /api/editor/schema
listScripts(): Promise<ScriptPackage[]>                             GET  /api/editor/scripts
readScript(key): Promise<ScriptDetail>                              GET  /api/editor/scripts/{key}
readChapter(key, chapterId): Promise<ChapterContent>                GET  /api/editor/scripts/{key}/chapter?id=...
writeChapter(key, chapterId, body): Promise<void>                   PUT  /api/editor/scripts/{key}/chapter?id=...
createChapter(key, chapterId, name): Promise<ChapterContent>        POST /api/editor/scripts/{key}/chapter
deleteChapter(key, chapterId): Promise<void>                        DELETE /api/editor/scripts/{key}/chapter?id=...
writeConfig(key, config): Promise<void>                             PUT  /api/editor/scripts/{key}/config
validateScript(key): Promise<ValidationReport>                      GET  /api/editor/scripts/{key}/validate
```

`chapterId` **必须 `encodeURIComponent`**（可能含 `/`）。
`readChapter`/`writeChapter`/`deleteChapter` 的 chapterId 走 query，不是路径段。
`writeChapter` 的 body 是 `{ name, events }`。
`writeConfig` 的 body 是 `{ config }`。
`createChapter` 的 body 是 `{ chapterId, name }`。

所有失败抛 `EditorApiError extends Error`（带 `status?: number`），与 `api/scripts.ts` 的 `ScriptImportError` 同构。

### 3.1 状态

```ts
interface UndoFrame {
  chapterId: string;
  name?: string;
  events: ScriptEventData[];
  /** 该帧对应的选中下标，撤销后光标回到原处 */
  selected: number;
}

export const store = reactive({
  // ---- 后端数据 ----
  schema: null as ScriptSchema | null,
  scripts: [] as ScriptPackage[],
  detail: null as ScriptDetail | null,
  chapter: null as ChapterContent | null,

  // ---- 界面态 ----
  loading: false,
  /** "flow" = 章节流程；"chapter" = 章节编辑（本批恒为 flow，E4 启用 chapter） */
  level: "flow" as "flow" | "chapter",
  /** 本批只有 flow */
  tab: "flow" as EditorTabKey,
  selectedEvent: 0,
  /** 事件属性栏展开（临时态） */
  propsExpanded: false,
  propsWidth: 720,

  // ---- 保存态 ----
  dirty: false,
  saving: false,
  lastSavedAt: null as number | null,

  // ---- 撤销栈 ----
  undoStack: [] as UndoFrame[],
  redoStack: [] as UndoFrame[],

  // ---- 校验 ----
  report: null as ValidationReport | null,
});
```

`EditorTabKey` 定义为原版 8 个 key 的联合类型（即使本批只渲染 flow），注释里写明「E3 起逐个启用」：
```ts
export type EditorTabKey =
  | "flow" | "config" | "characters" | "assets"
  | "validate" | "agent-chat" | "agent-settings" | "appearance";
```

常量：
```ts
export const UNDO_LIMIT = 100;
export const AUTOSAVE_DELAY = 800;      // 自动保存防抖
export const VALIDATE_DELAY = 2500;     // 校验比保存重，单独更长防抖
```

getters（用 `computed` 导出，或直接在组件里 `computed(() => ...)`；**统一放 store 里导出 computed**）：
```ts
export const scriptKey = computed(() => store.detail?.package.key ?? "");
export const chapters = computed(() => store.detail?.chapters ?? []);
export const canUndo = computed(() => store.undoStack.length > 0);
export const canRedo = computed(() => store.redoStack.length > 0);
```

### 3.2 actions

| 函数 | 行为 |
|---|---|
| `initEditor()` | 若 `store.schema` 为空 → `getSchema()`；再 `loadScripts()`。失败走 `notifyError` |
| `loadScripts()` | `loading=true` → `listScripts()` → 写 `store.scripts` → `loading=false` |
| `openScript(key)` | `readScript(key)` → `store.detail`；`level="flow"`；`chapter=null`；`selectedEvent=0`；清空 undo/redo 栈；`tab` 若不在已启用列表则回落 `flow`；随后 `void runValidation()` |
| `closeScript()` | `detail=null`、`chapter=null`、`report=null`、清栈、`level="flow"` |
| `openChapter(id)` | `readChapter` → `store.chapter`。**本批不切 `level`**（E4 才切），但要实现这个函数以备后用 |
| `setChapterName(name)` | `store.chapter.name = name` → `markDirty()` → 触发自动保存 |
| `markDirty()` | `dirty=true` → 800ms 防抖后 `saveNow()` |
| `saveNow()` | `writeChapter(scriptKey, chapter.id, {name, events})`，成功后 `dirty=false`、`saving=false`、`lastSavedAt=Date.now()`；失败 `notifyError` |
| `pushUndo()` | 把当前 `chapter` 拍一帧进 `undoStack`，清 `redoStack`，超 `UNDO_LIMIT` 从头丢 |
| `undo()` / `redo()` | 交换栈顶帧，回填 `chapter.events/name`，`selectedEvent=frames.selected`，`markDirty()` |
| `runValidation()` | `validateScript(scriptKey)` → `store.report`。**必须防抖**：2500ms 内重复调用合并成一次 |
| `deleteScript(key, name)` | 先 `confirmDialog("删除剧本", \`确定删除「${name}」吗？删除后不可恢复。\`)`；确认后调 `deleteChapter` 不适用 —— **本批后端没有 `editor_delete_script`**，见 3.3 |
| `createChapter(id, name)` | `createChapter` API → 成功后重新 `readScript` 刷新 chapters，`notify("已新建章节")` |
| `removeChapter(id)` | 先 `confirmDialog`，再 `deleteChapter` API → 刷新 chapters |
| `notifyError(msg, err)` | `alertDialog(msg, String(err))`（复用 `store/dialogStore`） |

- 点卡片 → `store.openChapter(ch.id)`（本批不切 level，所以点了没视觉变化，但要把 `selectedEvent` 归零 —— 或者干脆本批点击无操作，写注释 `E4：切到章节编辑`）。
- 用 `report.edges` 而不是前端自己推，是因为后端已经算好了（`ScriptValidator.checkGraph`）。**不要在前端重复实现一遍图算法**。

## 8. 快捷键

`ScriptEditorView.vue` 里 `onMounted` 挂 `window.keydown`：

| 键 | 行为 | 生效范围 |
|---|---|---|
| `Ctrl/Cmd + Z` | `undo()` | 编辑器内 |
| `Ctrl/Cmd + Shift + Z` | `redo()` | 编辑器内 |
| `Ctrl/Cmd + S` | `saveNow()`，`preventDefault` | 编辑器内 |

`onBeforeUnmount` 移除监听。输入框聚焦时不拦截 `Ctrl+Z`（让浏览器处理输入框自己的撤销）：判断 `document.activeElement` 是 `INPUT`/`TEXTAREA` 就跳过。
