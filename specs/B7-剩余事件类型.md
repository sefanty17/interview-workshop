## 现状锚点

- 事件分发：`backend/.../engine/InterviewEngine.java:347-355` 的 `switch`，已有
  narration / ai_dialogue / input / modify_character / free_dialogue / chapter_end，
  其余落 `NoopEvent`。
- 每请求一轮模型：引擎不在进程内挂起。`script:input` 后停轮，用户经
  `InterviewEngine.submitAndRun()`（InterviewEngine.java:209）续跑。**choice 照此模型**。
- 变量存取：`variable_info` JSON（EngineContext / ConditionEvaluator 已有求值器）。
- SSE 出口：`SseEventSink`（新事件要在这里加推送方法）。

## 任务一（后端）：9 个事件类 + 分发注册 + choice 挂起

Rust 原文（1:1 语义迁移，先通读再写）：
`references/lingchat/crates/ling-chat-main/src/ai_service/game_system/script_engine/events/`
- `choice_event.rs`（核心，逻辑最重）
- `dialog_event.rs`、`set_variable_event.rs`、`player_event.rs`、`present_pic_event.rs`
- `background_event.rs`、`background_effect_event.rs`、`music_event.rs`、`sound_event.rs`、`ambient_event.rs`

实现要点：
1. **ChoiceEvent**：
   - 构建选项列表：无 text 的兜底选项不发给前端；有 `condition` 且求值不过 →
     `disabled=true`、`reason=lock_hint`（choice_event.rs:41-63）。
   - emit `script:choice` payload `{choices, allowFree, duration?}`（duration 可空不序列化）。
   - 挂起 = 本轮到此停（发完事件即返回），并在 `variable_info` 记 `pendingChoice`
     （存原始 options + allowFree），供续跑匹配——这是 Rust oneshot 通道的持久化等价物。
   - `submitAndRun` 入口先查 `pendingChoice`：allowFree 时自由文本可转投；
     匹配规则照 choice_event.rs 后半段（用户选择文本与 option text 匹配，disabled 永不匹配；
     匹配后执行该 option 的动作/求值，再清 pendingChoice 续跑主循环）。
2. **DialogEvent**：设 currentCharacter → 组装台词。原版无 LLM 配置时走 `emit_plain_reply`
   直接发 `ai:reply`（带说话人）；有变量替换/函数调用就照 ScriptFunctions 现有设施做。
3. **SetVariableEvent**：按原版把键值写进 `variable_info`（set_variable_event.rs:1-104），
   不发 SSE。
4. **PlayerEvent / PresentPicEvent / BackgroundEvent / BackgroundEffectEvent /
   MusicEvent / SoundEvent / AmbientEvent**：解析字段 → 经 SseEventSink 推对应事件名 →
   返回 null 继续下一事件。payload 字段逐字对照 responses.rs 对应 struct。
5. 分发 switch（InterviewEngine.java:347）补 9 个 case；NoopEvent 注释同步更新。
6. 单测：choice 的条件禁用/allowFree 转投/disabled 不匹配三例 + set_variable 写入 +
   各通知类事件的事件名与 payload 字段断言（照 EngineFinishTest 现有风格）。

## 任务二（前端）：消费新事件

- `frontend/src/api/chat.ts`：parseSseStream 注册 8 个新事件名透传 store。
- `frontend/src/store/roomStore.ts` + `views/InterviewRoomView.vue`：
  - `script:choice` → GameDialog 渲染选项按钮组：disabled 项灰显 + reason 提示；
    allowFree 时输入框仍可用、提交文本转投同一 advance/submit 接口；
    duration 有值时显示倒计时（自动提交逻辑若 LingChat 前端有就照抄，先查
    `references/lingchat` 前端对 `script:choice` 的处理，**不自行发明**）。
  - `script:background` → 换房间背景；`script:present-pic` → 展示图片浮层。
  - `script:music` / `script:sound` / `script:ambient` → HTMLAudio 播放（Web 等价物），
    资源 404 静默忽略不报错。
  - `script:player` → 按 payload 在对话区插玩家侧展示行。
  - `script:background-effect` → 效果层（有对应物照抄，没有就记日志留空层）。
- 样式与交互对齐 LingChat 前端对应组件（在 references/lingchat 里搜事件名定位）。
