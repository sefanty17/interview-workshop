## 二、每页的固定骨架

原版所有设置页都是这个形态：

```html
<MenuPage>
  <MenuItem title="区块标题" size="normal|small">
    <template #header><SomeIcon :size="20" /></template>
    ...内容...
  </MenuItem>
</MenuPage>
```

`MenuPage` / `MenuItem` 已建好：`frontend/src/components/ui/Menu/`。直接 import，不要重写。

**`MenuItem` 的标题栏样式是统一的**（图标 + 标题 + 底部青色线），不要每页自己写标题。

### 卡片样式必须逐页照抄，不要统一

不同页面的卡片底色/圆角/描边**并不相同**。例如：

- 角色卡：`rounded-2xl border-white/20 bg-white/10 backdrop-blur-xl`
- 存档卡：`rgba(20,20,20,.45)` + `rounded-xl` + `border-white/10`
- 场景卡：`rounded-xl` + 自己的描边色

**正确做法**：打开原版对应页，找到那张卡片的根 class，原样抄。不要套用别的页面的样式，
也不要用本节以外任何"统一规范"。

## 三、文案：从中文语言包取，不要自己翻译

原版模板里是 `{{ $t("settings.xxx.yyy") }}`。对应中文在：

```
references/lingchat/src/locales/zh-CN/settings.ts
references/lingchat/src/locales/zh-CN/ui.ts
```

**把 `$t("...")` 替换成语言包里那句中文字面量**，不要改写成同义句。

术语映射（只对这几个词生效，其余原样）：

| 玩家 / 我的身份 | 求职者 / 我的简历 |

| 剧本 | 面试剧本 |
| 存档 | 面试存档 |
| 世界书 | 岗位知识库 |

## 四、数据

统一接 `frontend/src/store/appStore.ts` 的 `store.settings`（类型 `SiteSettings`，在 `data/mock.ts`）。

- 已有的字段直接用（如 `textSpeed` / `autoDelay` / `volumeCharacter` / `fontSize`）
- 原版有、我们没有的字段 → 在 `SiteSettings` 接口和 `defaultSettings` 里**新增**，命名沿用原版
- 不允许新增后端请求，全部走 localStorage 持久化
- 不允许把设置项做成"只能看不能改"的假控件

**所有交互必须真做**：滑块拖动改值、开关切换、下拉展开、按钮触发弹窗、删除要二次确认
（用 `store/dialogStore.ts` 的 `confirmDialog`，不许 `window.confirm`）。

---

## 五、控件样式：一律用原版

原版这几类控件的 class 在各页里重复出现，必须原样抄：

| 控件 | 原版长相 |
|---|---|
| 滑块 | 原生 `input[type=range]` + 自定义轨道/滑块头（青色圆点，左右标「弱/强」或数值） |
| 开关 | 胶囊形，开启青色，关闭灰白半透明 |
| 输入框 | `bg-white/10` 圆角，白色文字，`placeholder:text-white/50` |
| 下拉 | 同输入框，右侧箭头 |
| 主按钮 | `Button type="big"`（已建好） |
| 小按钮 | `px-3 py-1.5 text-xs rounded-lg` 一类 |
| 卡片内分隔 | `border-b border-white/10` |

**不要用我们旧的 `LcSlider` / `LcToggle` / `LcSelect`**（那是之前自造的近似版），除非原版本身就是那样。
旧的可以先留着不删，但不许在新页面里 import。

## 六、圆角 token

`SettingsPanel` 根节点已加 `lc-reset-radius`，面板内 `rounded-lg` = 8px、`rounded-sm` = 4px，
与原版 Tailwind 默认一致。直接用原版 class 即可，不要硬编码 px。

---

## 七、禁区

- 不动 `frontend/src/styles/*.css`
- 不动 `components/settings/{SettingsPanel,SettingsNav}.vue`、`components/base/*`、`components/ui/Menu/*`（角色页在用）
- 不动 `components/game/*`、`views/InterviewRoomView.vue`（房间线在做）
- 不动 `data/interviewers.ts`、`data/scripts.ts`、`data/`
- 不新增 npm 依赖
- 不许把多行设置折叠成一行、不许省略区块标题、不许省略 hover 态
- 不许出现"（占位）""待实现"字样留在成品里——功能可以用假数据，但界面必须是完整的
