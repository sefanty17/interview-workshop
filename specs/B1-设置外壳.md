## 三、Icon / Button 的搬法

### Icon.vue
原样复制，只改一处：不需要改。原版没有任何外部依赖，`html` 常量里的 32 个 svg 全部保留
（包括 `package`，即使插件页不做，按钮组件可能用到）。

`IconType` 联合类型一起导出。

### Button.vue
原样复制。`type` 的 9 个分支（big / menu / nav / select / delete / add / save / start / close / transparent）
全部保留，即使当前只用到 `nav` 和少数几个——后面的页面会用到。

`baseClasses` 与 `typeClasses` 的字符串**一个字符都不要改**，包括 `[text-shadow:...]` 这类任意值语法。

## 四、`store/settingsUi.ts`

原版的 `uiStore` 是 pinia 的全局 UI store，我们只需要其中两个字段。用 Vue 的 `reactive` 实现：

```ts
export const settingsUi = reactive({
  showSettings: false,
  currentSettingsTab: "character" as SettingsTab,
});
export type SettingsTab = "character" | "adventure" | "text" | "background"
  | "sound" | "history" | "achievement" | "save" | "advance" | "log";
export function openSettings(tab?: SettingsTab): void
export function closeSettings(): void
export function setTab(tab: SettingsTab): void
```

默认 tab 是 `character`（原版打开设置默认落在角色页，与截图一致）。

## 五、页面占位骨架（重要）

`pages/` 下建这 10 个文件（文件名与原版一致）：

```

SettingsAdventure.vue      剧本

SettingsHistory.vue        对话历史
SettingsAchievement.vue    成就
SettingsSave.vue           存档
SettingsAdvance.vue        高级设置
SettingsLog.vue            日志
```

**占位页不是空白页。**每个文件必须：

1. 从原版同名文件里读出**最外层容器的 class 串**，原样写在根 `div` 上。
   例：原版 `SettingsSound.vue` 的根节点 class 是 `p-4` 这类，就照抄。
2. 内部先放一个占位块，尺寸按原版内容区走：
   ```html
   <div class="rounded-xl border border-white/10 bg-white/[0.06] p-4 text-sm text-white/50">
     （B2 填充）
   </div>
   ```
3. **根节点 class 里的滚动、内边距、最大宽度不能省**——B2 只往里填内容，不再动外层。

`index.ts` 导出这 10 个组件。

## 六、SettingsNav.vue 的要求

照搬原版，逐项核对：

| 元素 | 原版值（必须一致） |
|---|---|
| 外层 | `relative flex h-full w-full items-center justify-between px-5` + `py-2`（桌面）/ `pt-safe pb-2`（移动） |
| Logo | `img` `ml-5 hidden w-20 xl:block`，路径 `@/assets/images/logo.png`（我们已放好） |
| nav 容器 | `custom-scroll relative flex h-full w-full flex-nowrap items-center justify-start gap-1 overflow-x-auto overflow-y-hidden px-2 duration-100 ease-in-out xl:[justify-content:safe_center]` |
| 指示条 | `bg-brand absolute bottom-[3px] left-0 z-10 h-1 w-0 rounded shadow-[0_0_10px_rgba(121,217,255,0.4)]` |
| 导航按钮 | `<Button type="nav" class="shrink-0" :icon="..." :class="{ active: ... }">` |
| 按钮内部文字 | `<p class="hidden whitespace-nowrap xl:block">文案</p>` |
| 关闭键 | `<Icon icon="close" :size="40" class="hover:text-accent flex cursor-pointer items-center justify-center rounded-full border-none bg-transparent p-1.5 text-white transition-all duration-300 ease-in-out hover:rotate-90 hover:bg-white/10" />` |

**删掉 plugins 按钮**（用户明确不做插件页）。其余 10 个按钮顺序不变。

文案（`$t(...)` 全部换成本字面量，这是唯一允许的文案改动）：

| 原版 key | 我们用 |
|---|---|
| nav.character | 角色 |
| nav.adventure | 剧本 |
| nav.text | 通用 |
| nav.background | 背景 |
| nav.sound | 声音 |

**指示条动画必须保留**：读原版 `moveIndicator` / `watch` / `onMounted` 的实现，
用 `getBoundingClientRect()` 取按钮相对容器的 left/width，赋给指示条的 `style.left` 与 `style.width`，

窗口 resize 时重算。

`closeSettings` 调用我们 store 的 `closeSettings()`，然后 `router.push("/")`。

## 七、SettingsPanel.vue 的要求

照搬原版结构，四层：

1. `blur-overlay`（`v-if="shouldShowOverlay"`，`:style="{ opacity: overlayOpacity }"`）
   样式见原版 `styles/` 或组件内 scoped style，`position: fixed` + `backdrop-filter: blur(...)`。
2. `settings-panel`（`flex h-full flex-col`，`slide-in-right` / `is-leaving` 动画类，`v-show="panelVisible"`）
3. 顶部 `<SettingsNav />`
4. 内容区 `relative w-full flex-1 overflow-hidden`，内部 `<Transition>` + `<KeepAlive>` + `<component :is>`，
   页面组件上挂 `class="absolute inset-0 overflow-y-auto"`

`slide-in-right` / `is-leaving` / `blur-overlay` 的 CSS 从原版全局样式里找（搜 `settings-panel`），
找不到就按原版 `SettingsPanel.vue` 的 scoped style 抄。**动画时长和延时一个都不能改。**

我们项目里没有 `uiStore.showSettings`，改用 `settingsUi.showSettings`。
