## 六、`SettingsCharacter.vue`

结构（照原版）：

```
<MenuPage>
  <MenuItem title="角色列表（切换角色会开始全新对话）">   ← 标题按截图，带 Rabbit 图标
    <div class="grid w-full grid-cols-1 gap-5 p-3.75 md:grid-cols-2">
      <CharacterCard v-for="..." />
      <button 虚线新建卡 v-if="最后一页" />
    </div>
    <分页条 v-if="totalPages > 1" />
  </MenuItem>

  <!-- 我们独有的：我的身份（LingChat 该版本没有，业务需要） -->
  <MenuItem title="我的身份">
    ...身份卡（见 §七）
  </MenuItem>

  <NewCharacterModal ... />
  <详情弹窗 ... />
</MenuPage>
```

数据源：`interviewers` 只有 4 个，`pageSize` 设 4（2×2 网格），分页条在 4 个时不显示（`totalPages = 1`），
这与截图一致（截图正好 4 张卡 + 1 张新建卡，占 2 行）。

等等——截图是 4 张卡 + 新建卡 = 5 格，2 列 2 行是 4 格。看截图：第一行 2 张卡，第二行 1 张卡 + 1 张新建卡。
所以 `pageSize = 4`，第 4 格是新建卡。我们的数据正好 4 个角色 → 第一页 3 张 + 新建卡？
不对，截图里第一行 DeepSeek + 钦灵，第二行风雪 + 新建卡 → 共 3 张角色卡 + 1 新建。

但实际有 4 个角色（风雪/钦灵/松子/DeepSeek）。截图只显示 3 个，第 4 个在第二页或没显示。

**按我们的数据来**：4 个角色 + 新建卡 = 5 格，`pageSize=4` 时第一页 4 个角色，新建卡放到最后一格需要 5 格。
简单处理：`pageSize = 4`，第一页放 4 张角色卡；新建卡放在列表末尾（跨页时在最后一页），
`grid` 自然流式布局。视觉与截图一致（都是 2 列卡片网格）。

## 九、圆角 token 问题（重要）

`frontend/src/styles/tokens.css` 把 Tailwind 的 `--radius-lg` 覆盖成了 22px（默认 8px），
`--radius-sm` 覆盖成 10px（默认 4px）。这会让照抄来的 `rounded-lg` / `rounded-sm` 全都偏大。

**你的任务**：在 `SettingsPanel.vue` 的根元素上加一个类 `lc-reset-radius`，并在它的
`<style scoped>` 里写：

```css
.lc-reset-radius {
  --radius-sm: 0.25rem;
  --radius-lg: 0.5rem;
  --radius: 0.25rem;
}
```

这样只影响设置面板内部，不动全局。加完确认导航按钮圆角仍是 8px、卡片圆角与原版一致。
