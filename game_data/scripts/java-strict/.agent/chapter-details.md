# 风雪 · 面试剧本 · 章节细节稿

## 第1章 · 自我介绍

会议室在三楼走廊的尽头，门牌是那种老式的铜色塑料片，边角已经磨白了。林舟在门口站了两秒，把手机调成静音，塞进裤兜，抬手敲门。

「进来。」

声音比想象中年轻，也比想象中冷。

推门进去，房间不大，一张长条会议桌靠窗摆着，窗外是下午三点的日光，被半拉的百叶窗切成一条一条。桌后坐着的人穿深蓝色西装外套，里面是白衬衫，头发在脑后盘得很紧，一丝都没乱。她面前摊着一台笔记本和一张打印出来的简历，旁边一杯水，杯壁上没挂一颗水珠——像是倒上之后就没动过。

「坐。」她抬了下眼，又低下去，笔尖在简历某一行停住。

林舟拉开椅子坐下，椅子腿在地面上蹭出一声轻响，他下意识地缩了下肩膀。

「谢谢。」

房间里安静了几秒，只有空调出风口的低鸣。

「我姓沈，沈聿。」她终于抬起头，「今天的面试由我负责。二十到三十分钟，中间我会打断你，你可以打断我，但不要问和岗位无关的问题。」

「好。」

「简历我看了。」她把那张纸往边上挪了挪，笔搁下来，「但简历上写的东西，我一般只信三成。剩下七成，得你自己说。」

她往前靠了一点。

「第一个问题，先做个自我介绍吧。三分钟，说清楚两件事——你是谁，你做过什么。」她顿了顿，补了一句，「别念简历，念简历我不如自己看。」

「明白。」

林舟吸了一口气，把背稍微往后靠了靠，让肩膀塌下去一点。这个动作他在镜子前练过。

「我叫林舟，今年二十四，本科计算机，毕业两年半，一直在做 Java 后端。」

沈聿没动，也没记，只是看着他。

「第一家公司是做物流系统的，人不多，我一个人从写接口到上线都跟。第二家现在还在职，做的是会员和订单这一块，QPS 不算高，但业务链路长——从下单、支付回调、库存扣减到退款，中间有七八个服务串在一起。」

他说到这儿停了一下，看她的反应。她还是没反应。

「技术上，我平时写得最多的是 Spring Boot 和 MyBatis，中间件用得比较熟的是 Redis 和 RocketMQ。JVM 这块……我调过两次线上问题，一次是内存泄漏，一次是长时间的 Full GC，都是自己从头查到尾的，但我不敢说我很懂。」

这句话出口的时候，他听见自己的声音有一点点收紧，于是把语速放慢了些。

「缺点也很清楚。我没带过人，没做过技术选型，写代码偏实用主义，遇到很漂亮的抽象设计会本能地绕开——这个我知道是短板。」

他收住，点了下头：「大概就是这些。」

沈聿把笔拿起来，在纸上写了一个字，很短。

「三分钟，你用了两分四十。」她说，「省下的二十秒，你没有用来补一句『我很希望能加入贵公司』。」

「我怕说了您会觉得我在凑时间。」

「你觉得我会这么想？」

「我不知道您怎么想。」林舟说，「但我知道那句话对您判断我没有帮助。」

沈聿的视线在他脸上停了一拍，然后落回简历。

「行。第二个问题。」她把简历翻了一页，「你说你不敢说你很懂 JVM。那我们就从这句『不敢说』开始。」

「好。」

「你自己挖的那个内存泄漏，从头讲。不要讲结论，讲你怎么知道那里漏的。」

林舟点了下头，手指在桌面上无意识地敲了两下，又赶紧收回来。

「一开始是运维报的告警，说那个服务的老年代占用每天涨一点，涨了大概一周，涨到 85% 的时候开始频繁 Full GC。」

「你怎么确认是泄漏，不是缓存用得多？」

「先看 GC 之后的水位。如果每次 Full GC 完，老年代能掉回 30% 以下，再慢慢涨上去，那是正常在用；但那台机器 Full GC 完还留着 60% 左右，连着几天都是这样，那就不是缓存，是有东西被一直引用着。」

「说下去。」

「然后我 dump 了一份堆，用 MAT 看 Dominator Tree。最大的一块是某个本地缓存，一个静态 Map，key 是用户 ID,value 是一个业务对象。代码里 put 进去之后，删除的逻辑写在了一个 catch 块里——那个 catch 只处理特定异常，别的异常走不到。」

他说到这儿看了一眼沈聿。她的表情没变，但笔停着。

「所以不是泄漏，是漏删。」他说。

「嗯。」沈聿应了一声，很轻，听不出是赞同还是别的什么，「那个 Map，你后来换成什么了？」

「换成 Redis，加了过期时间。但说实话，那个数据量本来就不该用分布式缓存——一周最多几千个 key，我其实只是换成了 Caffeine，设了 maximumSize 和 expireAfterWrite。」

「为什么一开始不用 Caffeine？」

林舟愣了一下。

「因为……我写那段代码的时候，项目里还没有人用过 Caffeine，我不想为一个缓存引入一个新依赖。」他停了一下，「现在想想这个理由挺蠢的，它本来就是 JDK 生态里最常规的东西。」

「不蠢。」沈聿说，「只是你把『别惹麻烦』排在了『别出错』前面。这个顺序在很多团队里是对的。」

她终于写了第二笔。

「最后一个问题。」她合上简历，「我这儿只剩十分钟了。你给我讲一件事——你做过的事情里，你自己最不满意的那一件。」

林舟沉默了几秒。

「去年双十一之前，我把一个订单查询接口的缓存 key 设计错了。」他说，「我用的是『用户 ID + 订单状态』，没带分页参数。结果第一页的数据把后面的都盖住了，用户翻到第二页看到的还是第一页的订单。」

「怎么发现的？」

「客服反馈的。已经跑了两天。」

「谁的责任？」

「我的。设计评审的时候我把 key 贴在文档里了，但评审的人看的是逻辑，没人盯 key。而我自己默认『这种小事不会错』。」

沈聿把笔放下，双手交叠在桌上。

「好。」她说，「我这边问完了。」

她起身，把简历收进文件夹。

「结果一周内会通知你。走廊右手边有电梯。」

林舟站起来，椅子又蹭了一声。他走到门口，手搭在把手上，回过头。

「沈老师。」

「嗯？」

「刚才那个自我介绍，我是不是说得太长了。」

沈聿看了他一眼，那是整个面试里她第一次露出一点不像职业表情的东西——嘴角动了一下，很浅。

「不长。」她说，「你省下来的那二十秒，比你说的话有用。」
