# Java 后端 · 严格三轮 · 章节细节稿

## 第01章 · 破冰与自我介绍

id: intro

面试间的门是在九点整被推开的。

蔡智豪进去的时候，屋里已经坐好了人。长条会议桌的另一头，风雪把笔记本电脑的屏幕压得很低，只抬了一下眼皮就收回去，像是不太愿意把视线浪费在门口这种事上。她穿着深蓝色的外套，帽檐压着，头顶的一对猫耳在空调风口吹出的冷气里微微动了动，听见脚步声也只是把桌上那份简历推到面前，用两根手指按住了边角。

「坐吧。」她说，「门带上，外面吵。」

屋里安静得有点过分。玻璃幕墙外是早高峰还没散尽的车流，隔音玻璃把那点声音滤成了很轻的一层白噪声。桌上摆着一杯没动过的热水，杯壁上的水汽已经凝成一条细线滑到杯底。

蔡智豪拉开椅子坐下。风雪这才抬起头，蓝色的眼睛在帽檐的阴影里显得格外淡，视线在他脸上停了大约三秒，不长不短，足够让人意识到自己正在被完整地打量一遍。

「今天不问废话。」她合上笔记本的屏幕，双手交叠放在上面，「先说说你自己——」

她顿了顿，像是临时想起了什么，又补了一句：

「一分钟。超时我会打断。」

蔡智豪端起水杯抿了一口，把杯子放回桌上的时候，杯底碰到桌面发出一声很轻的响。他开口，从学校讲到专业，再讲到最近在做的那个项目，语速一开始有点赶，说到第三句的时候稳了下来。

风雪没有低头看表。她只是把视线斜过来一点，落在他搭在桌沿的手上，听他把那段自我介绍说完。

「一分钟到了。」她在他把最后一个字收住的同时开口，声音没什么起伏，「你这分钟里说了三次『负责』，一次明确的动作都没有。负责什么？点按钮，还是画流程图？」

蔡智豪愣了一下，说出了一个具体的模块，还有他在其中写过的那些东西。

风雪没接话，把简历翻过去一页，指尖在某一行上停住。

「行，那从简历上最有分量的那个项目说。」她抬起眼，「你在里面具体负责哪部分？不要念 JD，说你自己动手改过的那几行。」

蔡智豪把项目从头讲了一遍：一开始怎么想的，中间卡在什么地方，最后怎么绕过去的。讲到一半的时候，他下意识用了一个很含糊的说法——「然后我们优化了一下」。

风雪的笔在纸上停了。

「优化。」她把这两个字重复了一遍，语调平平的，像是念一个没听过的词，「『优化了一下』是句废话。改之前是什么数，改之后是什么数，你怎么知道它真的变好了。这三个问题里，你至少能回答一个吧？」

会议室里安静了两秒。空调风口的冷气正对着这一侧吹，蔡智豪这才发现她一直没动过的那杯热水，到这会儿也还是满的。

他重新组织了一遍语言，把那个项目里真正动过手的地方、用过的办法、以及为什么最后选择了这一个办法讲清楚。

风雪听完，把笔放下，在简历的空白处写了一行很短的字。

「勉强算个回答。」她把那页翻过去，帽檐下的猫耳又一次转向空调风口，声音仍然淡得像在说今天的天气，「自我介绍这一关，我见过太多背稿子的。你至少没背。不过——」

她抬眼看他，一字一顿地说：

「项目是你自己的，别让它听起来像别人的。」

说完，她把笔记本重新翻开，屏幕的光打在她脸上。

「下面问点正经的。」
