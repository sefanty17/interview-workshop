### 2. 两份 schema 不一致

- **实际生效**：`backend/src/main/resources/schema-h2.sql`（151 行，7 表，含 `sender_role_id`、`characters`、`user_settings`）

`clamp(60+min(25,5n)+min(15,avgLen/40),0,100)`——只看「回答条数」和「平均字数」。这是占位实现，和题目要的「多维量化评分」完全是两件事。做 P0-#2 时应整条替换，不要在这套公式上叠补丁。

- **payload 字段**：camelCase，与 Rust `serde(rename_all)` 一致。
- 这三类改动由主线亲自复核，不外包。
