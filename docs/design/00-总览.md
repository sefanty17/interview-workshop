> 方针见 `docs/00-项目方针.md`。本文件是该方针在设计层的落地：**跨页共用的常量与组件规格**，

## 0. 设计基调

LingChat 是「明亮天空背景 + 居中偏右立绘 + 左侧超大字菜单」的游戏式首页，
叠加「深色半透明毛玻璃」的全屏滑入式设置面板。两套观感共存：
首页是亮的，点进任何功能页后是暗的。**照搬这个双层结构，不自创第三种风格。**

## 1. 设计 Tokens

出处：`src/assets/styles/variables.css`、`base.css`

### 1.1 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--accent-color` | `#79d9ff` | 唯一主题色：激活 Tab、滚动条、聚焦框、hover 发光 |
| `--color-brand` | `var(--accent-color)` | Tailwind 里以 `bg-brand` / `text-brand` / `border-brand` 引用 |
| 玻璃面板底色 | `rgba(255,255,255,0.1)` | 所有卡片/设置区块底色 |
| 玻璃描边 | `rgba(255,255,255,0.125)` ~ `white/20` | 卡片边框 |
| 遮罩层 | `rgba(0,0,0,0.7)` + `blur(4px)` | 设置面板背后压暗 |
| 对话框顶部渐影 | `rgba(0,14,39,0.3 → 0.6)` | 对话区顶部压暗带 |
| 副标题蓝 | `#6eb4ff` | 对话框副标题 |
| 情绪标签粉 | `#ff77dd` | 情绪词/追问提示 |
| 浅色按钮底 | 底 `#e9ecef` 字 `#495057` | 分页/大按钮浅色态 |
| 下拉 option 兜底 | 底 `#16202c` 字 `#fff` | 深色 select 原生选项 |

**只允许一个主题色。** 状态色仅用现成语义色：加入=cyan、选中=emerald、删除=red、详情=白玻璃。

### 1.2 字体

| 场景 | 字体 |
| --- | --- |
| 首页大字菜单 | `Maoken Assorted Sans`，`public/fonts/MaokenAssortedSans.woff2` |
| 界面正文 | `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, ...` |
| 代码/JSON | `ui-monospace, "Cascadia Code", Consolas, ...` |

Tailwind 类里字体名空格写成下划线：`font-['Maoken_Assorted_Sans',-apple-system,...]`。

### 1.3 字号

| 位置 | 规则 |
| --- | --- |
| 根字号 | `html { font-size: clamp(12px, min(2.5vw, 2.5vh), 16px) }`，页面级禁滚动 |
| 首页菜单项 | `clamp(40px, 4vw, 72px)`；宽高比 > 2 时 `clamp(28px, 3vw, 52px)`；手机端二级菜单 32px |
| 设置页标题 h4 | 600 weight，`text-shadow: 0 0 2px rgba(0,0,0,0.5)` |
| 对话框角色名 | `text-2xl font-bold`；副标题 `text-xl`；正文 `text-base` |
| 输入控件 | `font-size: max(16px, 1em)`（防 iOS 聚焦缩放） |

### 1.4 圆角 / 间距 / 层级

- 卡片 `rounded-2xl`(16px)；设置区块 12px；按钮 `rounded-lg`(8px) 或胶囊 `rounded-full`
- 区块内边距 15px；卡片内边距 `p-4`；卡片网格 `gap-5`
- 首页 z-index：背景 `-2` → 流星/星星 → 立绘 `3` → 压暗层 `4` → 菜单列 `5`
- 设置面板：遮罩 `999`、面板 `1000`、面板内弹窗 `50`

出处：`src/assets/styles/base.css`，以下四块**逐字复制**：

## 4. 设置面板（所有功能页的外壳）

出处：`SettingsPanel.vue`、`SettingsNav.vue`、`ui/Menu/MenuPage.vue`、`MenuItem.vue`

### 4.1 外壳

1. 遮罩 `.blur-overlay`：`fixed inset-0`、`rgba(0,0,0,0.7)` + `blur(4px)`、`z-999`、淡入 0.3s
2. 面板 `.settings-panel`：`fixed inset-0 z-1000`、背景透明、从右滑入 0.42s（`cubic-bezier(0.32,0.72,0,1)`）
3. 内部上下两段：固定顶部导航 + 内容区 `overflow-y-auto`（Tab 切换带滑动动画）

### 4.2 顶部导航

- `flex justify-between px-5 py-2`；左 Logo（`w-20`，仅 xl）、中按钮组（可横滚）、右关闭钮
- 关闭钮 40px，hover **旋转 90°** + `bg-white/10`
- 导航按钮：`px-[15px] py-[10px] mx-[5px] rounded-lg text-base font-bold`；默认白字透明底、hover 变主题色、激活主题色 + `bg-white/10`
- 指示条：4px 高、圆角、`bg-brand`、发光 `0 0 10px rgba(121,217,255,0.4)`，缓动 `0.3s cubic-bezier(0.18,0.89,0.32,1)`

### 4.3 Tab 映射（11 个，顺序即导航顺序）

| # | LingChat | 面试工坊 | id |
| --- | --- | --- | --- |
| 1 | 角色 | 面试官 | `persona` |
| 2 | 羁绊 | 剧本冒险 | `adventure` |
| 3 | 通用 | 通用 | `text` |
| 4 | 背景 | 背景 | `background` |
| 5 | 声音 | 声音 | `sound` |
| 6 | 成就 | 成就 | `achievement` |
| 7 | 存档 | 存档 | `save` |
| 8 | 高级设置 | 高级设置 | `advance` |
| 9 | 日志 | 日志 | `log` |
| 10 | 插件 | 插件 | `plugins` |

LingChat 的「对话历史」Tab 不设，内容归首页「面试记录」模块。

### 4.4 MenuPage

- 居中 flex-wrap，`gap-5 px-3 py-6`
- 宽度：默认 70%；宽高比 < 1 时按 `70 + (1-ratio)*60` 加宽；绝对宽度 < 1024px 时线性加宽到 100%

### 4.5 MenuItem（区块卡片）

- 容器 `rgba(255,255,255,0.1)`、`border-radius: 12px`、`padding: 15px`
- 标题行：图标 + h4（600 weight 白字带 2px 阴影），下接 `border-b-2 border-brand`，`mb-4 pb-2`
- 尺寸：`large` 100% 宽；`small` `calc(50% - 12.5px)`，≤768px 时 small 也全宽
- Tab 切换：新页 100% 滑入、旧页滑出 150%，`0.32s cubic-bezier(0.32,0.72,0,1)`

### 4.6 表单控件

| 控件 | 规格 |
| --- | --- |
| 大按钮 `Button type="big"` | 全宽 `p-3 rounded-lg text-base font-bold`；默认 `#e9ecef`/`#495057`；hover 变主题色底白字 + `translateY(-2px)` + 发光 `0 4px 10px rgba(121,217,255,0.4)` |
| 下拉 select | `rounded-xl border-white/10 bg-black/20 px-3 py-2 text-sm`，option 强制 `#16202c` |
| 分页按钮 | 浅色态 `px-4 py-1.5 text-sm` |
| 字段标签 | `text-xs font-medium text-white/60` |

## 6. 面试房间（对话界面）

出处：`components/game/standard/GameDialog.vue`、`assets/styles/dialogue-text.css`

- **对话框**：底部，宽按 MenuPage 同款 70%→100% 算法居中，最大高 `40dvh`，顶部 40px 渐变压暗带 `rgba(0,14,39,0.3→0.6)`
- **标题栏**：角色名 `text-2xl font-bold`，副标题 `text-xl text-[#6eb4ff]`，右侧操作钮用 `Button type="nav"`
- **打字机**：逐字符「上浮+淡入」`tw-char-rise`：`translateY(0.35em)+opacity 0 → 0,1`，必须在全局 CSS（动态 span，scoped 无效）
- **情绪标签位**：`text-xl font-bold text-[#ff77dd]`

## 8. 响应式

| 条件 | 行为 |
| --- | --- |
| 宽高比 > 2 | 主菜单 2 列网格，菜单字号降档 |
| < 768px | MenuItem small 全宽；二级菜单字号 32px；菜单项左对齐可换行 |
| < 1024px | 内容容器 70% 线性加宽到 100% |
| 手机端 | 面板内容区支持左右滑动切 Tab（阈值 50px，横向位移须大于纵向）；导航条横滚并居中激活项 |
| 全部 | 页面级 `overflow: hidden`，滚动只在组件内部 |
