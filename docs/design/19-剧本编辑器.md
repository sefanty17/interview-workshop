# 19 · 剧本编辑器（≈ LingChat ScriptEditor）

- **路由**：`/script-editor`，独立全屏页（编辑器需要工具栏 + 多 Tab 工作区）
- **数据模型**：`interview_script` + `interview_chapter`，事件类型照搬 LingChat 剧本引擎
- **前身**：LingChat `components/script-editor/*`（`ChapterFlow.vue` / 章节时间线 / 字段编辑器 / 校验）

## 章节流程

- 每章一张卡：`code` + `name` + `{events.length} 个事件`，`intro_chapter` 那张带「开场」角标。
- 卡片底部标出口，由该章最后一条 `chapter_end` 反推：
  - `linear` → `→ {next_chapter}`；`next_chapter` 缺省或为 `end` → `→ end`
  - `ai_judged` → `AI 判定 → a / b`；`branching` → `条件分支 → …`
  - 没有 `chapter_end` → 红色 `⚠ 无章节结束`
  - 除 intro 外没被任何跳转指向的章节 → 红色 `无人进入`
- 点卡片切换下方事件时间线。

## 事件时间线

六种事件，插入时 `chapter_end` 只能一条且固定在末尾，其它类型插在它之前。

| 类型 | 徽标色 | 可编辑字段 |
|---|---|---|
| `ai_dialogue` | 蓝 | `character`（默认 MAIN）、`prompt` |
| `input` | 青 | `hint`（占位提示，本项目扩展字段） |
| `narration` | 灰 | `text` |
| `free_dialogue` | 紫 | `prompt` |
| `modify_character` | 橙 | `action`（show/hide）、`character`、`duration` |
| `chapter_end` | 粉 | `end_type` + 按类型分支 |

`chapter_end` 分支：

- `linear`：只填 `next_chapter`（空 = 结束）。
- `branching` / `ai_judged`：`prompt` + `options[]`，每项 `name` + `next`（可加 `condition` / `default`）。

> **必须能填 `next`**。原版 `chapter_end_event.rs` 在 LLM 选完分支后取的是 `opt["next"]`，
> 取不到就回落到第一个选项的 `next`，再取不到直接 `"end"` —— 整个剧本当场终止。
> 早期种子只写了 `name`，已修正（`gen_script_seed.py` 输出 `{name, next}`）。

## 剧本设置

- 基本信息：`script_name`、`code`（只读）、`description`、`intro_chapter`。
- 面试参数：`job_code`、`level`、`company_style`、`recommand_start`、`interviewer_code`、
  `script_settings.{total_questions, time_limit, follow_up_depth}`。

## 校验

纯前端计算，结果分级：

| 级别 | 规则 |
|---|---|
| 错误 | `intro_chapter` 指向不存在的章节 |
| 错误 | 跳转目标（含 `options[].next`）不存在且不是 `end` |
| 错误 | 某章没有 `chapter_end` |
| 错误 | `branching` / `ai_judged` 缺 `prompt` 或选项 < 2 |
| 错误 | 某个分支没有跳转目标（引擎会直接结束剧本） |
| 提醒 | 某章没有任何事件 |
| 提醒 | 除 intro 外某章没有任何入口 |

全部通过显示 `✓ 未发现问题`。4 个种子剧本当前均为 0 错误。

## 数据来源

- 浏览器侧只读镜像：`frontend/src/data/scripts.ts`（由 `scripts/gen_scripts_ts.py` 从
  `data/seed/scripts.json` 生成，与后端种子同源）。
- 「保存」只写 localStorage；接后端后改走 `PUT /api/scripts/{code}`。
