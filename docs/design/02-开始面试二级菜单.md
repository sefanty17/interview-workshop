# 02 · 开始面试二级菜单

- **位置**：首页内嵌状态（不占路由）
- **原型**：`references/lingchat/src/components/views/menu/page/GameModeOptions.vue`
- **复用度**：100%

## 布局

与主菜单同位置同字号的 StartItem 列表（窄屏时二级项字号降为 32px）：

```
自由面试          → 进 /interview
剧本面试（禁用）   → 灰色占位，P2 接剧本系统
返回              → 滑回主菜单
```

## 切换动画

- 主菜单 → 二级菜单：主菜单 `slide-left`（向左 120% 淡出），二级菜单 `slide-right` 进
- 返回：反向
- 参数：`0.4s cubic-bezier(0.7, 0, 0.2, 1)`（规范 §3.5）
- 退场元素立即 `position: absolute; pointer-events: none`，防布局跳动
