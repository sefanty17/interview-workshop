## 菜单项（StartItem）

- 六项：开始面试 / 继续面试 / 面试记录 / 面试设置 / 剧本编辑器 / 创意工坊
- 新增的两项（面试记录、剧本编辑器）与其余项**外观完全一致**，只有文案区别
- 「继续面试」无进行中会话时禁用（opacity-50，hover 不变色）
- hover：上浮 8px + 放大 1.05 + 白色发光，回弹缓动（规范 §3.3）

## 交互

- 鼠标视差：背景/立绘/星星三层不同系数跟随，移出回位
- 「开始面试」→ 整列左滑退场，二级菜单右滑进（见 02）
- 其余项 → 压暗层淡入 + 对应功能页从右滑入
- Logo：右上角，`h-[16vw] max-w-[40vw]`，hover scale 1.05；本轮用文字 Logo「面试工坊」占位
