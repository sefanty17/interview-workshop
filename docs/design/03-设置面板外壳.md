# 03 · 设置面板外壳

- **承载**：11 个 1:1 复刻 Tab（面试官/剧本冒险/通用/背景/声音/面试历史/成就/存档/高级设置/日志/插件）+ 1 个新增 Tab（面试规则，排最后）
- **原型**：`references/lingchat/src/components/settings/SettingsPanel.vue`、`SettingsNav.vue`、`ui/Menu/MenuPage.vue`、`ui/Menu/MenuItem.vue`
- **数值规格**：规范 §4

> 现阶段实现方式：设置仍是独立路由 `/settings`，页面自带「天空背景压暗」底层 +
> 面板外壳，视觉与 LingChat 一致。P1 再改为盖在首页上的真滑入面板。

## 结构

```
┌─ 底层：天空背景 + rgba(0,0,0,.7) + blur(4px) ─────────────┐
│ [Logo] 面试官 剧本冒险 通用 背景 声音 面试历史 成就 存档 … [×]│ ← 导航条
│         ▔▔▔▔ 激活项下主题色发光指示条                        │
│ ┌──────────── 内容区（宽 70% 居中，纵向滚动）────────────┐  │
│ │  MenuItem 卡片（large 全宽 / small 半宽）              │  │
│ └────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────┘
```

## 导航条（SettingsNav）——1:1

- `flex justify-between px-5 py-2`；左 Logo（w-20，仅 xl 显示）、中按钮组（横向可滚动）、右关闭钮
- 关闭钮：40px 图标，hover 旋转 90° + `bg-white/10` 圆底；点击返回首页
- nav 按钮：`px-[15px] py-[10px] mx-[5px] rounded-lg text-base font-bold`，图标 18px stroke 2.5
  - 默认：白字透明底，hover 字变主题色
  - 激活：字主题色 + 底 `bg-white/10`
- 指示条：4px 高、`bg-brand`、发光 `0_0_10px_rgba(121,217,255,0.4)`，跟随激活按钮，
  缓动 `0.3s cubic-bezier(0.18,0.89,0.32,1)`
- **Tab 顺序固定**：面试官 → 剧本冒险 → 通用 → 背景 → 声音 → 面试历史 → 成就 →
  存档 → 高级设置 → 日志 → 插件 → 面试规则（新增项永远在最后）

## 内容区（MenuPage）——1:1

- 宽度算法：默认 70%；宽高比 <1 或宽度 <1024px 时线性放宽至 100%
- `flex-wrap gap-5 px-3 py-6`，滚动只在容器内（页面级 overflow hidden）
- Tab 切换：新页从右/左 100% 滑入、旧页滑出 150%，`0.32s cubic-bezier(0.32,0.72,0,1)`
- 手机端：内容区左右滑动切 Tab（阈值 50px，横向位移须大于纵向）

## MenuItem 区块卡——1:1

- `background: rgba(255,255,255,0.1); border-radius: 12px; padding: 15px`
- 标题行：20px 图标 + h4 白字 600 + 主题色 2px 下边框，`mb-4 pb-2`
- large = 100% 宽；small = `calc(50% - 12.5px)`（≤768px 变全宽）
