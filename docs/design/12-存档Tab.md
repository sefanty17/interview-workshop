# 12 · 存档 Tab（≈ LingChat 存档，1:1）

- **原型**：`settings/pages/SettingsSave.vue`

## 区块（自上而下）

```
MenuItem large「创建新存档（会记录当前面试）」
└─ 输入框(glass) + 绿色创建钮（宽 10% min-w-16）

MenuItem large「存档列表」
└─ 2 列卡片网格，卡片结构（1:1 照搬存档卡）：
   ┌──────────────────────────┐
   │ [左：截图/预览区 h-48] No.1 · 2026.10.20 11:30 │
   │           面试标题（双击可改名）                  │
   │           - - - - - - - - - -                   │
   │           最后一条对话（斜体 2 行截断）            │
   │ [读取][覆盖][删除]  ← 蓝/绿/红三钮               │
   └──────────────────────────┘
```

- 进行中的面试对应「当前存档」：主题色边框高亮 + 左上角「当前」胶囊标
  （LingChat 用粉色标示当前存档；我们统一主题色 `#79d9ff`）
- 左预览区：无截图时显示岗位名首字 + 灰图标占位
- 「继续面试」首页菜单项落地页就是本 Tab
