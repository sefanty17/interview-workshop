### 两条贯穿性根因（解释多处 ✗）

1. **`base.css` 的按钮 reset 压住了 Tailwind 工具类**：`src/styles/base.css:24-30` 的 `button, input, select, textarea { font: inherit; color: inherit; }` 是**未分层的普通 CSS**，而 Tailwind v4 的 `text-base` / `font-bold` / `text-[#79d9ff]` / `font-['Maoken…']` 全在 `@layer utilities` 内。未分层规则优先级高于任何 layer，于是：nav 按钮字号 14px、字重 400、激活字色白色；卡片「选择」按钮 12px 变 14px；菜单的 Maoken 字体被 `font: inherit` 换成微软雅黑。已确认 `font-['Maoken…']` 规则确实生成（`"Maoken Assorted Sans", -apple-system, …`），只是被覆盖。
2. **旧版 `menu.css` 的 `.start-item` 规则仍在全局生效**：`src/styles/menu.css:192-258` 定义了 `font-size: clamp(27px, 2.9vw, 44px)`、`padding: 7px 0`、`color: #e8f4ff`、`hover { transform: translateX(12px) }`。`StartItem.vue` 现在已改用 Tailwind 类，但这些未分层规则仍然命中，造成首页 3 / 5 / 6 / 7 的偏差（hover 时 Tailwind 的 `translate/scale` 与它的 `transform` 叠加，出现「向上+放大+右移」）。

## 额外发现（不在 20 项规格表内，但影响验收）

### 1（P0，严重）：鼠标一移动，首页立绘被推出屏幕

- 现象：首页任意 `mousemove` 之后，角色整体消失，只剩左上角一小块矩形（实际是图片右下角的版权水印角），鼠标移出后也不恢复，必须刷新。
- 实测：静止时 `img` 的 rect = `x 0 / y 43.3 / 1440×813.4`；悬停后 = **`x -727.2 / y -368.0 / 1440×813.4`**，同一个框整体左移 727px、上移 411px。
- 根因：模板里的 `-translate-x-1/2 -translate-y-1/2` 在 Tailwind v4 生成的是独立属性 `translate: -50% -50%`；`HomeView.vue:44-66` 的视差逻辑又写内联 `transform: translate(calc(-50% ± dx), calc(-50% ± dy))`。两者**累加**：computed `transform` = `matrix(1,0,0,1,-727.2,-411.3)`，`translate` 仍为 `-50% -50%`，于是 -50% 被算了两次。`handleMouseMove` 与 `handleMouseLeave` 都写 `transform`，所以移出后依旧错位。
- 影响：用户第一次动鼠标后首屏就「空」了；`home-hover.png` 中左上角那块矩形即此状态，不是截图错误。

## 结构性差异（有意取舍）

1. **Logo 是纯文字版**（「面试工坊 / INTERVIEW LAB」两行），没有图形 Logo 素材；本轮不引入位图，避免版权与加载问题。副作用是它和菜单层同为 `z-[5]` 且 DOM 在前，被全屏菜单容器盖住，连 hover 都进不去。
2. **缺流星 / 星点层**：`components/menu/StarField.vue`、`HoloFigure.vue` 存在但未挂载到 `HomeView`，首页目前只有「背景 → 立绘 → 文字 Logo → 菜单」四层。本轮取舍：静态截图优先，动效层后置。
3. **设置页是独立路由 `/settings`**（`fixed inset-0` 全屏），不是从首页滑入的面板；关闭按钮执行 `router.push("/")` 而非「关闭面板」。有意路由化，方便刷新、深链和截图。
4. **「开始面试」没有二级菜单**：LingChat 是悬停展开二级项，我们直接开始面试（其余五项各自跳页）。本轮取舍：减少一层交互，先把主流程跑通。
5. **立绘用宽幅场景插画而非透明角色抠图**：`alona.png` 2560×1446（不透明像素 23.5%，其余透明），渲染 1440×813 后角色居中、版权水印落在右下角。有意复用现成素材；代价是「立绘」更像背景场景的一部分，且尺寸过宽（铺满视口宽度）。
6. **设置页 12 个 Tab 全平铺无图标**，LingChat 为分类折叠/带图标布局；且「面试历史」等 7 个 Tab 目前是占位文案（`本区块待迁移`），属迁移未完成，不在本轮视觉范围。
7. **人设详情是 Teleport 到 body 的模态**（宽 896px、blur 40px、radius 24px），LingChat 为面板内展开/切换视图。
